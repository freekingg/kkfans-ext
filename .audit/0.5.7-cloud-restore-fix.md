## 在 0.5.6 源码复现的缺陷

1. 空本地上传队列的缓存检查运行期间，手动同步被标为 rerun，但 finally 要求 pending.size > 0 才继续，导致下载请求未执行。
2. 手动下载继续使用已有 since 游标；资料本地缺失、云端旧资料没有近期修改时，下载空结果仍报同步成功。
3. 手动下载意图只在内存，后台暂停重启后不能保证请求继续执行。
4. “已同步”不能区分上传和真正完成云端下载；手动按钮忽略后台返回的错误。

## 修复范围

- 手动恢复意图写入独立持久化键 cloudPullRequest，不依赖上传队列是否为空。
- 手动请求先分页完整核对会话资料；消息沿用增量水位，不重新上传历史消息。
- fullMetadata 标记随恢复断点保存，失败/重启继续对应页。
- 继续保护本地未上传修改，保持原有三方合并与冲突确认。
- 显示实际下载时间、会话资料和消息数量；无下载完成记录的旧“success”显示恢复待确认。
- 捕获手动同步后台错误；下载失败保留请求，阻止上传。
